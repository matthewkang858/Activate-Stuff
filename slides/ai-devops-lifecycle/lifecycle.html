How to read it: six steps of the product development lifecycle, clockwise from Ideation and Roadmapping. Each box: the header, a line on how AI is transforming that step, then the incumbent, the best-funded challenger and a niche pick. 1 Ideation and Roadmapping. Amplitude: Global Agent answers usage questions in plain language and the Feedback Agent synthesizes surveys and tickets (Feb 2026); public, $410M ARR, 5,200+ customers. Simile: AI simulations of customers to pre-test launches and concepts; $100M (Feb 2026) then $200M+ at a $2B valuation (Jul 2026); CVS Health, Wealthfront, Deloitte, Gallup. Dovetail: research synthesis (customer intelligence platform since Oct 2025), now with Digital Twins built from real calls, tickets and research; says 40% of the Fortune 500 use it. 2 Product Definition. Productboard: Spark (GA) drafts specs from feedback and a connected GitHub repo, then hands them to coding agents via MCP; 6,000+ customers. Linear: Linear Agent scopes specs from customer requests and Code Intelligence flags technical constraints (public beta); $100M+ ARR; $2.5B tender valuation (Aug 2026). ChatPRD: PRD specialist; bootstrapped and profitable; claims 250K+ PMs. 3 Design. Figma: Make (prompt to prototype) and an on-canvas agent (GA since Oct 6, 2026) that also reviews flows from simulated users; over half of $10K+ ARR customers used the agent weekly by July 31, 2026. Lovable: prototypes from prompts and Jira/Linear tickets; $400M Series C at $13.3B (Aug 2026). Magic Patterns: prototypes from a team's own components; $6M Series A; 1,500+ product teams. 4 Build. GitHub Copilot: coding agent turns issues into PRs; 50M users; one in three GitHub PRs involves an agent (Microsoft, Jul 2026). Claude Code: whole-task agent; $2.5B+ run-rate by Feb 2026; top coding agent in Stack Overflow's 2026 survey. Factory: model-agnostic Droids; $200M at $5B (Sep 2026). Cursor is now owned by SpaceX; Cognition is the standalone alternative. 5 Test and QA. Tricentis: agentic QE platform on Tosca and qTest; ~$500M ARR; Gartner Leader (Oct 2026). mabl: agentic testing platform; Gartner Challenger in the same report; $77M raised. Momentic: plain-English tests and Mo, an AI QA agent swarm (Sep 2026); $15M Series A. Gartner (Oct 2025 report): 70% of enterprises will have integrated AI-augmented testing tools by 2028, up from about 20% in early 2025. 6 Monitor. Datadog: Bits AI builds dashboards from a prompt, investigates alerts and sets anomaly baselines (Preview); Q2 2026 revenue $1.12B. Resolve AI: AI SRE that triages alerts to root cause; $190M+ raised, $1.5B valuation. Traversal: accuracy-first AI SRE that builds a causal model of the production environment to trace alerts to root cause, read-only by default; $48M seed and Series A (Sequoia, Kleiner Perkins, June 2025) plus Amex Ventures (March 2026); DigitalOcean, Cloudways, American Express.
