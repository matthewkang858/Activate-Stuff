How to read it: six steps of the end-to-end product development lifecycle, clockwise from Ideation and Roadmapping. Each box gives what AI is changing at that step, then the incumbent, the best-funded challenger and a niche pick; for each company, the first line is the offering and the second is traction or funding. Sources: Ideation, Build, Test and QA, and Monitor come from the AI DevOps lifecycle case study (as of Oct 12, 2026). Product Definition and Design are new research (Oct 13, 2026), each figure checked against the company's own announcement, filing or site. 1 Ideation and Roadmapping (case study Plan stage). Atlassian: Rovo Dev Agents turn Jira issues into code plans, code and PR reviews; Teamwork Collection passed 1M seats in Q2 FY26. AWS Kiro: spec-driven agentic IDE, GA in 2026 as the replacement for Amazon Q Developer. Tessl: spec registry of 10,000+ library specs and a package manager for agent skills; $125M raised at a reported ~$750M valuation. 2 Product Definition (new research). Productboard: Spark agent turns customer feedback into delivery-ready specs and can push them to coding tools; now generally available; 6,000+ customers. Linear: Linear Agent helps draft project briefs (Sep 2026) and Loops turns meeting notes into follow-up work; past $100M ARR; $2.5B valuation in a $99M employee tender (Aug 2026), not a new round; not AI-born (founded 2019). ChatPRD: bootstrapped PRD specialist with an MCP hand-off to Cursor, VS Code and Claude; 250K+ PMs and 1M+ docs are the company's own claims. 3 Design (new research). Figma: Figma Make (prompt-to-app) and an agent on the canvas; over 80% of paid customers above $10K ARR were consuming AI credits weekly at June 30, 2026 (Q2 2026 results). Lovable: prompt-to-app builder used for prototypes; $400M Series C at $13.3B led by Menlo Ventures (Aug 2026). Magic Patterns: prototypes built from a team's own design system and components; $6M Series A (Nov 2025); 1,500+ product teams (Apr 2026). No company yet covers user-journey simulation with strong sourcing. 4 Build (case study Code stage). GitHub Copilot: coding agent turns issues into PRs; Agent HQ opens it to rival agents; 50M users. Claude Code: whole-task coding agent; $2.5B run-rate by Feb 2026, over half enterprise. Factory: Droids for coding, review, testing and migrations; $200M at $5B (Sep 2026). 5 Test and QA. Tricentis: agentic quality engineering on Tosca and Testim; ~$500M ARR in 2025. QA Wolf: AI writes Playwright and Appium tests that QA Wolf engineers maintain, with an 80% coverage guarantee; $36M Series B. Momentic: plain-language end-to-end tests; $15M Series A; customers report 80% coverage in days. 6 Launch and Monitor (case study Monitor stage). PostHog: LLM evals beside product analytics; incumbent in its niche. Dynatrace: agentic operations on Davis causal AI; its own benchmarks claim problems solved up to 3x faster. Braintrust: evals that gate prompt and model changes in CI/CD; $80M Series B led by ICONIQ. Not shown: the case study's review (CodeRabbit, Graphite), release (LaunchDarkly, ServiceNow, Octopus Deploy), deploy (GitLab, Harness, Pulumi) and operate (AWS DevOps Agent, Resolve AI, Traversal) examples.
